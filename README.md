# Solution for Project 1 of Data Visualization Course of Pere Pau Vázquez

## File overview and execution overview:
**Main Files:**
- `stefano_galiano_jan_mantsch_collab.ipynb`: Collab Document
- `stefano_galiano_jan_mantsch_streamlit.py`: Streamlit
- `simpsons_cleaning.py`
- `requirements.txt``

To run from scratch, follow the following course:
1. Move to project source, then execute `pip install -r requirements.txt``
2. Then **either** run `stefano_galiano_jan_mantsch_collab.ipynb`(Collab), **or** `simpsons_cleaning.py` if you want to run the streamlit before running the notebook.
3. To launch streamlit run `streamlit run stefano_galiano_jan_mantsch_streamlit.py`. **ONLY WORKS AFTER RUNNING `simpsons_cleaning.py`**

- The files `question_*.py` as well as `conf.py` and `util.py` are there to support the streamlit application and make the streamlit file less cluttered.
- Please also note the `.streamlit/conf.toml` which contains important theming for the overall streamlit design to work.

Enjoy!
